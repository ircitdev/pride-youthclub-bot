# 📋 Описание работы бота Pride YouthClub Bot

## 🤖 Общее описание

Pride YouthClub Bot - это Telegram-бот для автоматизации реферального маркетинга Клуба Омоложения ПРАЙД. Бот работает с UTM-метками, автоматически создает вкладки в Google Sheets, отслеживает приглашения и предоставляет инструменты администрирования.

---

## 🔄 Основной сценарий работы

### 1️⃣ Переход по ссылке с UTM-меткой

Пример: `https://t.me/PRIDEyouthClub_bot?start=pridefit`

**Что происходит:**
1. Бот получает параметр `start=pridefit`
2. Проверяет наличие вкладки `pridefit` в Google Sheets
3. Если вкладки нет → создает автоматически
4. Проверяет наличие пользователя по Telegram ID
5. Если пользователь новый → записывает данные

**Структура вкладки в Google Sheets:**
```
Колонка A: Время перехода
Колонка B: Имя пользователя
Колонка C: Username
Колонка D: Telegram ID
Колонка E: Метка (pridefit)
Колонка F: Статус (первый 10 / обычный)
```

**Антидублирование:** Повторные переходы одного пользователя не добавляются в таблицу.

## 👭 Система приглашения друзей

### Формат ссылки
```
https://t.me/PRIDEyouthClub_bot?start={{utm1}}_friend_f{{user_id}}
```

**Где:**
- `{{utm1}}` - оригинальная метка пользователя (например, pridefit)
- `{{user_id}}` - Telegram ID приглашающего

**Пример:**
`https://t.me/PRIDEyouthClub_bot?start=pridefit_friend_f123456789`

### Вкладка для приглашенных друзей

Создается автоматически: `{{utm1}}_friend` (например, `pridefit_friend`)

**Структура:**
```
Колонка A: Время приглашения
Колонка B: Кто пригласил (ID/username)
Колонка C: Кого пригласил (ID)
Колонка D: Имя пользователя
Колонка E: Статус (новый / уже в базе)
```

**Логика:**
- Проверяется наличие приглашенного по Telegram ID
- Дубли не добавляются
- Статус "новый" ставится только при первом приглашении

## 📊 Структура Google Sheets

Бот автоматически создает и управляет следующими вкладками:

### 1. Users (основная таблица)
```
timestamp | user_id | username | full_name | ref_source | action | object | bonus
```

**Назначение:** Логирование всех действий пользователей

### 2. InviteLinks (реферальные ссылки)
```
ref_id | bot_link | created_at | created_by
```

**Назначение:** Хранение сгенерированных реферальных ссылок

### 3. Bonuses (бонусы рефералов)
```
ref_id | total_refs | total_bonus | updated_at
```

**Назначение:** Накопление бонусов по рефералам

### 4. Payments (платежи)
```
timestamp | user_id | username | full_name | tariff | price | period | status | ref_source | notified
```

**Назначение:** Учет всех платежей через YooKassa

### 5. {{utm1}} (динамические вкладки по меткам)
```
Время перехода | Имя пользователя | Username | Telegram ID | Метка | Статус
```

**Пример:** `pridefit`, `instagram`, `vk`

### 6. {{utm1}}_friend (приглашенные друзья)
```
Время приглашения | Кто пригласил | Кого пригласил | Имя пользователя | Статус
```

**Пример:** `pridefit_friend`, `instagram_friend`

## 🔐 Система безопасности

### Антидублирование
- Проверка по Telegram ID перед записью
- Повторные записи блокируются
- Статус "уже в базе" для дублей в friend-ссылках

### Права доступа
- Команда `/admin` доступна только администраторам
- Проверка через функцию `is_admin()`
- Администраторы указываются в `.env` файле

### Защита от флуда
- Задержка между сообщениями при массовой рассылке
- Обработка ошибок при отправке

---

## 🎯 Бонусная система

### Начисление бонусов

| Действие | Бонус |
|----------|-------|
| Подписка на канал (по реферальной ссылке) | +10 |
| Вступление в закрытую группу (по реферальной ссылке) | +500 |
| 25% от платежа приглашенного | Зависит от суммы |

**Пример:**
- Пользователь оплатил тариф 990₽
- Реферал получает: 990 × 0.25 = 247₽ бонусов

### Уведомления
- Приглашенный получает уведомление о начисленных бонусах
- Реферал получает уведомление о комиссии от платежа
- Администраторы получают уведомления о новых платежах

---

## 💳 Платежная система

### Тарифы
1. **1 месяц** - 990₽
2. **3 месяца** - 2673₽ (скидка 10%)
3. **12 месяцев** - 8910₽ (скидка 25%)

### Интеграция с YooKassa
- Создание платежей через API
- Проверка статуса платежа
- Автоматическая выдача доступа после оплаты
- Начисление бонусов рефералу

---

## 🔄 Фоновые процессы

### Мониторинг платежей
- Проверка каждые 20 секунд
- Поиск новых записей в таблице Payments
- Отправка уведомлений администраторам
- Автоматическая пометка как "notified"

**Работает для:**
- Платежей через бота
- Внешних добавлений в Google Sheets

## 📝 Логирование действий

Все действия логируются в таблицу `Users`:

**Типы действий (action):**
- `started` - запуск бота
- `subscribed` - подписка/вступление
- `ref_bonus` - начисление бонуса рефералу

**Объекты (object):**
- `bot` - запуск бота
- `channel` - подписка на канал
- `group` - вступление в группу
- `Комиссия 25% от оплаты` - бонус от платежа
